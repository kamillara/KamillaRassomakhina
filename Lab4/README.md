# Расчёт скорости резания при токарной обработке

## 1. Название проекта и вариант

Проект «Расчёт скорости резания при токарной обработке» — лабораторная работа 4 «Модульная организация проекта».

## 2. Требования к среде

Python 3.10+ (нужен для конструкции match-case и аннотации `float | None`).

## 3. Запуск

- В VS Code: открыть папку проекта и нажать **F5** (конфигурация `.vscode/launch.json` уже настроена).
- В терминале: `python main.py`
